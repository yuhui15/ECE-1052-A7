The three steps on the Apple-Silicon Mac
1. Put the modified YAML file in your home directory

Download the file above and put it in:

/Users/MyUserName/

So the complete path would be:

/Users/MyUserName/py3.11_AI_EXTENDED_MAC_ARM64.yml

You can also put it elsewhere; the command in step 3 simply needs the correct path.

2. Open Terminal

On the Mac, there is no need for the Windows Anaconda Prompt.

Open:

Applications → Utilities → Terminal

Then verify that Conda is available:

conda --version

You should get something similar to:

conda 25.x.x

If conda isn't recognized, Anaconda/Miniconda needs to be initialized in the shell first.

You can also verify that you're actually running Apple-Silicon Conda with:

conda info

Look for:

platform : osx-arm64

Conda supports osx-arm64 explicitly, and on a native Apple-Silicon installation it is normally the default target platform.

3. Create the environment

In Terminal, execute:

conda env create -f ~/py3.11_AI_EXTENDED_MAC_ARM64.yml

That's the direct Mac equivalent of your Windows command.

Then activate it:

conda activate py3.11_AI_EXTENDED

And verify:

conda info --envs

You should see:

py3.11_AI_EXTENDED

Conda's documented procedure is exactly this general pattern: conda env create -f environment.yml, followed by conda activate <environment>.
