1. Put the YAML file in your user directory

For example:

C:\Users\MyUserName\py3.11_AI_EXTENDED.yml
2. Open Anaconda Prompt

Open the Windows Start menu and search for:

Anaconda Prompt

Then launch it.

You can optionally verify Conda is available with:

conda --version
3. Create the environment

If the YAML file is in C:\Users\MyUserName, enter:

conda env create -f py3.11_AI_EXTENDED.yml

Conda will read the name: entry in the YAML file and create the environment with that name.

Then activate it with:

conda activate py3.11_AI_EXTENDED

and, if you want to verify it:

conda info --envs
One small improvement

You don't actually need to put the YAML file in C:\Users\MyUserName. You can put it anywhere and give Conda the full path, for example:

conda env create -f C:\Users\MyUserName\Downloads\py3.11_AI_EXTENDED.yml

The -f option tells Conda which environment-definition file to use.

So the answer is: yes—your Windows 10 procedure is also a Windows 11 procedure. You don't need a different YAML file merely because the operating system changed from Windows 10 to Windows 11.
